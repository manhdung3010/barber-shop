# Thư mục chứa Font chữ cục bộ (Local Fonts)

Bạn có thể tải các file font (định dạng `.woff2`, `.woff`, `.ttf`, hoặc `.otf`) và thả trực tiếp vào thư mục này:

Đường dẫn: `d:\barber-web\public\fonts\`

---

## Các font gợi ý cho phong cách Dark Luxury Barber:

1. **Clash Display** (hoặc **Cabinet Grotesk** / **Syne**):
   - Dùng cho Tiêu đề lớn (Display Headings, Headline, Logo).
   - Tải các file: `ClashDisplay-Bold.woff2`, `ClashDisplay-Variable.woff2` (hoặc `.ttf`).

2. **Be Vietnam Pro** (hoặc **Plus Jakarta Sans** / **Satoshi**):
   - Dùng cho Thân bài & Mô tả dịch vụ (Body text - dấu tiếng Việt cực kỳ đẹp và thanh thoát).
   - Tải các file: `BeVietnamPro-Regular.woff2`, `BeVietnamPro-Medium.woff2`, `BeVietnamPro-SemiBold.woff2`.

3. **JetBrains Mono** (hoặc **Space Mono**):
   - Dùng cho Thông số kỹ thuật, Chỉ số đo lường, Giá tiền, Chỉ mục `01 / FADE`.
   - Tải các file: `JetBrainsMono-Regular.woff2`, `JetBrainsMono-Bold.woff2`.

Sau khi bạn thả file font vào đây, hãy nhắn cho tôi tên file font bạn vừa ném vào, tôi sẽ kích hoạt và cấu hình toàn bộ font trong CSS ngay lập tức!
